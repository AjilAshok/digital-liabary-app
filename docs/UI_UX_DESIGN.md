## Global header
- Search input accessible from every major screen.
- Notifications.
- Current user and role.
- Profile/logout.

## Everyday actions
- The home screen places permission-aware links to find or add books, scan a barcode, and read a book cover above the library figures.
- The header provides a book-search shortcut, and the navigation uses familiar labels such as Books, Book copies, and Shelves & locations.
- An empty book list offers an Add a book action to users with catalogue-write permission.

## Search experience
Search by title, author, author number, ISBN, accession number, publisher, category, rack or shelf. Show suggestions while typing, but debounce requests. Provide filters and paginated results. Distinguish title results from exact copy results.

## Book details
Show bibliographic/edition metadata, authors, cover and description; show stock summary and a separate table of individual copies with accession, status, condition, acquisition, and location.

## Scanner experience
Mobile-first camera screen with mode selection: ISBN barcode, cover OCR, manual entry. Show camera permission guidance, camera switch, capture/retry, match candidates, source/confidence and confirmation form.

## Accessibility and usability
Keyboard navigation, visible focus, labels, adequate contrast, clear validation, responsive tables, loading/empty/error states, confirmation for destructive actions.
